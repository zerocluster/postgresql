# RPC v1

### API connect URLs

- API HTTP URL: `http://localhost:81/`
- API WebSockets URL: `ws://localhost:81/`

<!-- tabs:start -->

#### **WebSockets**

```javascript
import Api from "@corejslib/core/api";

const api = new Api( "ws://localhost:81/" );
```

#### **HTTP**

```javascript
import Api from "@corejslib/core/api";

const api = new Api( "http://localhost:81/" );
```

<!-- tabs:end -->

## PostgreSQL

### Get WAL file

<!-- tabs:start -->

#### **JavaScript**

```javascript
const res = await api.call( "/v1/postgresql/get-wal", server_names );
```

#### **Shell**

```sh
curl \
    -H "Authorization: Bearer <YOUR-API-TOKEN>" \
    "http://localhost:81/v1/postgresql/get-wal"
```
