# RPC v1

### API connect URLs

- API HTTP URL: `http://localhost:81/`
- API WebSockets URL: `ws://localhost:81/`

<!-- tabs:start -->

#### **WebSockets**

```javascript
import Api from "@corejslib/core/api";

const api = new Api( "ws://localhost:81/" );
```

#### **HTTP**

```javascript
import Api from "@corejslib/core/api";

const api = new Api( "http://localhost:81/" );
```

<!-- tabs:end -->

## PostgreSQL cluster instance

### Get instance status

<!-- tabs:start -->

#### **JavaScript**

```javascript
const res = await api.call( "/v1/postgresql/get-status" );
```

#### **Shell**

```sh
curl \
    -H "Authorization: Bearer <YOUR-API-TOKEN>" \
    "http://localhost:81/v1/postgresql/get-status"
```

### Start cluster

<!-- tabs:start -->

#### **JavaScript**

```javascript
const res = await api.call( "/v1/postgresql/start", options );
```

#### **Shell**

```sh
curl \
    -H "Authorization: Bearer <YOUR-API-TOKEN>" \
    "http://localhost:81/v1/postgresql/start"
```

<!-- tabs:end -->

- `options`

<details>
    <summary>JSON schema</summary>

<!-- tabs:start -->

#### **JSON**

```json
{
    "anyOf": [
        {
            "type": "object",
            "properties": {
                "role": {
                    "const": "primary"
                }
            },
            "additionalProperties": false,
            "required": [
                "role"
            ]
        },
        {
            "type": "object",
            "properties": {
                "role": {
                    "enum": [
                        "standby-synchronous",
                        "standby-asynchronous"
                    ]
                },
                "replicationHostname": {
                    "type": "string",
                    "format": "ip-address"
                }
            },
            "additionalProperties": false,
            "required": [
                "role",
                "replicationHostname"
            ]
        }
    ]
}
```

#### **YAML**

```yaml
anyOf:
  - type: object
    properties:
      role:
        const: primary
    additionalProperties: false
    required:
      - role
  - type: object
    properties:
      role:
        enum:
          - standby-synchronous
          - standby-asynchronous
      replicationHostname:
        type: string
        format: ip-address
    additionalProperties: false
    required:
      - role
      - replicationHostname
```
